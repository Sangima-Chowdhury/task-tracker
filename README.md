# Task Tracker

A simple Flask-based task tracking web app that allows users to add and delete tasks.

## Features
- Add tasks
- View task list
- Delete tasks
- Store task data locally
- Basic Flask routing
- HTML form handling

## Technologies Used
- Python
- Flask
- HTML
- Git & GitHub

## What I Learned
This was one of my first Flask projects. It helped me understand routes, templates, form submission, redirects, and how Python can be used to build interactive web applications.

## Why I built this

I built this project to practice Python and understand how web apps work using Flask.  
It helped me learn how to handle user input, routes, and saving data.
