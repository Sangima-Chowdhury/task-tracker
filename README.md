# Task Tracker App

This is a simple web app I built using Python and Flask while learning backend development.

The app lets you add tasks, mark them as complete, delete them, and it saves everything so your list stays even after restarting.

## Features

- Add new tasks
- Mark tasks as complete
- Delete tasks
- Tasks are saved to a file

## How to run it

1. Make sure Python is installed
2. Install Flask:
   pip install flask
3. Run the app:
   python app.py
4. Open your browser and go to:
   http://127.0.0.1:5001

## Tech used

- Python
- Flask
- HTML

## Why I built this

I built this project to practice Python and understand how web apps work using Flask.  
It helped me learn how to handle user input, routes, and saving data.
